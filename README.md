# Hot streets, far from parks? Urban heat and walking access to public green space in Brussels

> **Status: work in progress.** Phase 1 (data audit) is complete. Method, results, figures and the StoryMap will follow.

## Question

Which statistical sectors of the Brussels-Capital Region combine high summer land surface temperature (LST) and poor **walking** access to a public green space, and how many people live there?

This project describes **associations between sectors**. It does not claim causes, and it does not describe individuals.

## Data

All sources were audited by read-only scripts (`00_audit/`) before any analysis. Details: `docs/tableau_donnees.md` (in French).

| Source | Content | Version | Licence |
|---|---|---|---|
| Landsat 8 and 9, Collection 2 Level-2 (USGS), via Microsoft Planetary Computer | Surface temperature (`lwir11`), quality bands, red and near-infrared reflectance | Summers 2020-2025 (24 clear overpasses) | Public domain; courtesy of the U.S. Geological Survey (doi:10.5066/P9OGBGM6) |
| UrbIS (Paradigm) | Brussels-Capital Region boundary; street axes | Downloaded Nov. 2026 | Region boundary: SPF Finances open data licence (cadastral plan); street axes: CC-0 |
| Statbel | Statistical sectors (1 Jan 2026), population by sector (2026, 2025), population grid with variable cell size (1 Jan 2025) | 749 sectors in Brussels | CC BY 4.0 |
| Brussels Environment | Publicly accessible green spaces (2024); green space deficiency zones | 1 305 green spaces | CC-BY |
| OpenStreetMap, via the Overpass API | Street and footpath network | As of 1 Nov 2026 | ODbL, © OpenStreetMap contributors |

Each download script records the exact request and download date next to the raw data.

## Method

*To be fixed in phase 2, before any result.* Main choices already made:
- **Heat:** relative summer LST (per overpass, difference to the regional median, then median over the summer).
- **Access:** the Brussels Environment definition (a green space under 1 ha within 200 m, or of 1 ha or more within 400 m), measured **along the walking network**, with a straight-line variant for comparison.
- **Population:** Statbel population 2026, placed within sectors using the population grid or buildings.

## How to reproduce

1. Install [Miniforge](https://github.com/conda-forge/miniforge).
2. Create the environment from the repository root:
   ```
   conda env create -f environment.yml
   conda activate chaleur
   ```
   `environment.yml` lists the requested packages (portable). `environment_lock.yml` records the exact versions used (Windows).
3. Run the scripts in numerical order, from the repository root, e.g. `python 00_audit\00_verif_environnement.py`.

## Known issues

- In the author's environment, `scipy` 1.17.1 is installed from conda-forge (`INSTALLER` = `conda`) but has no `conda-meta` record, so `conda list` reports it as `pypi`. It was moved by hand to the conda dependencies of `environment_lock.yml`. No effect on results.
- In the Brussels Environment green space layer, the `area_m2` attribute is in hectares. Areas are always recomputed from the geometry.

## Limitations (known so far)

- Landsat measures **surface** temperature, not air temperature, at late-morning overpass time only (no afternoon peak, no night).
- The thermal band is measured at 100 m and delivered at 30 m: results are given by sector, not pixel by pixel.
- Clear summer overpasses are unevenly spread across June to August depending on the year.
- 2 785 residents (0.22 % in 2026) are registered in an unknown sector and cannot be mapped.
- The population grid (1 Jan 2025) is experimental (Statbel Datalab) and one year older than the population (1 Jan 2026).
- The OSM date is fixed by the request (`[date:...]`); the response does not contain explicit proof of that date.
- Green spaces in Flanders near the regional border are not included.
